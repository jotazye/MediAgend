# MediAgend

## Sobre o projeto
O MediAgend é uma proposta de sistema web para gerenciamento de consultas em postos de saúde públicos, desenvolvida como parte do Projeto Integrador de Tecnologia da Informação da UFMS.

O projeto surgiu a partir da análise de dificuldades no processo de agendamento da USF Mário Dedini I, em Piracicaba/SP, como filas, atrasos, conflitos de horários e dificuldades no controle de faltas.

## Objetivo
Planejar uma solução digital para organizar os agendamentos, facilitar a comunicação com os pacientes e melhorar o gerenciamento das consultas.

## Funcionalidades previstas
- Cadastro de pacientes e médicos
- Visualização de horários disponíveis
- Agendamento, cancelamento e reagendamento de consultas
- Confirmação prévia e notificações
- Controle de comparecimento e faltas
- Histórico de consultas
- Gerenciamento administrativo da agenda
- Prevenção de conflitos de horários

## Tecnologias propostas
- HTML, CSS e JavaScript
- React para a interface web
- PostgreSQL para o banco de dados
- Git e GitHub para versionamento e documentação

## Situação atual
O projeto está em fase de análise de requisitos, planejamento e modelagem conceitual. Ainda não existe uma aplicação funcional disponível para instalação ou utilização.
